Setup Instantâneo CLI oficial

Comando de Inicialização White-Label

Configure os ícones no seu projeto com apenas um comando. O CLI copia todos os arquivos SVG para a pasta de assets e gera o arquivo de inicialização pronto.

Modo Interativo (Perguntas no terminal):
npx @erikbernardo/white-label-icons init
Modo Direto via Flags:
npx wl-icons init --prefix=minhaempresa --tag=empresa-icone --assets=src/assets/icones -y
NG

Uso em Angular (8 a 20+)

No seu src/main.ts ou app.config.ts:

import { configureIcons } from '@erikbernardo/white-label-icons';

configureIcons({
  prefix: 'wl',
  tagName: 'wl-icone',
  basePath: '/assets/icones/'
});

No template HTML de qualquer componente:

<!-- Via Custom Element -->
<wl-icone nome="bx-user" tamanho="24" cor="#3b82f6"></wl-icone>

<!-- Ou via classe CSS -->
<i class="wl-bx-user"></i>
JS

React, Vue & Web Geral

No ponto de entrada (ex: index.jsx, main.js):

import { configureIcons } from '@erikbernardo/white-label-icons';

configureIcons({
  prefix: 'wl',
  basePath: '/icones/'
});

No seu JSX ou HTML:

<i class="wl-bx-cart-check" tamanho="32" cor="#10b981"></i>
